# Petal Ledger

A quote and flower-recipe builder for event florists. This is a prototype that runs on mock data.

```bash
npm install
npm run dev      # http://localhost:5173
npm run build
```

Data is saved in your browser's localStorage. Use **Reset demo data** in the sidebar to restore the mock data.

See [PLAN.md](./PLAN.md) for the product plan, data model, pricing formula and roadmap.
